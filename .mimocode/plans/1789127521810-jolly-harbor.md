# SuperAdmin Dashboard Full Redesign Plan

## Overview

Complete redesign of all 6 SuperAdmin pages + fix dead settings + fix fake data + add missing features. Target: modern, usable, powerful admin dashboard worthy of a real SaaS platform.

### 2.3 Add proper input types

**File:** `frontend/src/components/superadmin/settings/PlatformSettingsSection.tsx`

| Setting Pattern | Input Type |
|---|---|
| Boolean (`true`/`false`) | Toggle switch |
