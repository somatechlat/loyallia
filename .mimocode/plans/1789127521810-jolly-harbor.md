# PLAN: Restore Vault Secrets + Complete All Remaining Work

## Problem

Vault on production has only **39 keys** (version 3) but `.bootstrap_secrets.production.env` has **48 keys**. Missing critical keys:

- `google_oauth_client_id`
- `google_oauth_client_secret`
- `google_oauth_redirect_uri`
- `google_service_account_json`
- `jwt_private_key`
- `jwt_public_key`
- `apple_cert_pem`
- `apple_cert_key_pem`
- `apple_wwdr_cert_pem`
- `twilio_test_account_sid`
- `twilio_test_auth_token`
- `age_public_key`

This causes: Google Login button not showing, Apple/Google Wallet features broken.

## Root Cause

When I fixed `postgres_password` via the Vault API using Python `merge-patch`, I fetched the CURRENT Vault data (which was already incomplete at version 2), updated one key, and wrote it back — preserving the incomplete state. The original bootstrap must have failed to seed all keys (possibly the `_b64` decoding failed for multiline values).

## Fix: Re-seed Vault from bootstrap secrets file

The `vault-init` container's `init.sh` script reads ALL keys from `.bootstrap_secrets.production.env` and does an atomic `vault kv put` which REPLACES all secrets. Re-running it will restore all missing keys.

### Steps

1. **Remove vault-init container** so it's not marked as "completed":
   ```bash
   sshpass -p '...' ssh root@140.82.15.48 "docker rm -f loyallia-vault-init"
   ```

2. **Restart vault-init** which will re-seed all secrets:
   ```bash
   sshpass -p '...' ssh root@140.82.15.48 "cd /opt/loyallia && docker compose up -d vault-init"
   ```

3. **Wait for completion** and verify key count increased.

4. **Restart API** to pick up new secrets:
   ```bash
   sshpass -p '...' ssh root@140.82.15.48 "docker restart loyallia-api"
   ```

5. **Verify** Google OAuth config returns `enabled: true`:

6. **Restart all services** that depend on secrets (celery workers, whatsapp-bridge, etc.)
